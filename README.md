# house-of-briar

A fresh storefront landing page for House of Briar, inspired by a soft, elevated market aesthetic.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

- `index.html` — page layout
- `styles.css` — visual design and responsive styling
- `script.js` — small interactions for the product filters and newsletter form
